# Cloud Linux Lab

My beginner project while learning cloud engineering, starting with Linux.

## Scripts
- `scripts/system-info.sh`: prints disk, memory, uptime and top processes
- `scripts/backup.sh`: creates a timestamped backup of my notes

## Usage
    chmod +x scripts/*.sh
    ./scripts/system-info.sh

## What I learned
- some few new linus commands/options, making new directory, some file operations etc.
